# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who takes part in the project's spaces (issues, pull requests,
discussions, reviews) is expected to follow it.

## Project-specific expectation

Respect for patients is part of respectful conduct here. Never post patient data, PHI, or text taken
from MIMIC-IV or any other clinical record, even if you believe it is de-identified. See
[docs/data-and-compliance.md](docs/data-and-compliance.md).

## Reporting

Report unacceptable behaviour privately to the maintainer, [a2psilva](https://github.com/a2psilva),
through GitHub. Reports are handled confidentially and follow the enforcement guidelines of the
Contributor Covenant.
